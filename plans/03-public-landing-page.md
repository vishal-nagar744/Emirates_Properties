# Module 03: Public Landing Page & Discovery

## Objective
Provide a polished, responsive public landing page (`/index.html`) explaining the platform, highlighting the welcome bonus, showcasing featured projects, and offering clear calls to action.

---

## 1. Landing Page Sections (`index.html`)

### 1. Header / Navbar
- Brand Logo & Name (`PrimeSpace`)
- Navigation Links: `Projects`, `Experience`, `FAQ`
- Action Buttons: `Log in` (light), `Create account` (primary)

### 2. Hero Section
- Background imagery with sleek overlay gradient
- Headline: *"Find a project worth building your journey around."*
- Platform description & Welcome Bonus callout (*"Get ₹100 Demo Bonus when you register"*).
- Live search bar filtering project collection.
- Action Buttons: `Get Started`, `View Projects`

### 3. How It Works (6-Step Grid)
1. `01 · Create Account`
2. `02 · Receive Welcome Bonus`
3. `03 · Choose a Project`
4. `04 · Activate Project`
5. `05 · Receive Daily Commission`
6. `06 · Manage Your Demo Wallet`

### 4. Featured Projects Collection
- Display 4 curated demo project cards:
  - **Premium Project** (₹1,000 / ₹10 daily / 30 days)
  - **Smart Gadget Project** (₹2,000 / ₹25 daily / 60 days)
  - **Lifestyle Project** (₹1,500 / ₹18 daily / 45 days)
  - **Premium Project Plus** (₹3,000 / ₹40 daily / 90 days)
- Cards include: Image, Tag, Wishlist Heart, Location, Rating, Price/Activation Amount, CTA (`View project →`).

### 5. Platform Features Section
- Highlights: Daily Commission Tracking, Project Management, Demo Wallet, Order History, Secure Account, Referral Tracking.

### 6. FAQ Section
- Interactive `<details>` elements answering core questions:
  - What is the platform for?
  - Is the dashboard public?
  - Does the design work on mobile?

### 7. Footer
- Branding & platform summary
- Column links: Platform, Workspace, Account, Legal (Terms, Privacy)
- Copyright & disclaimer footer band.
