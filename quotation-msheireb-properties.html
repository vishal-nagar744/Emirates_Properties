02 · Scope of work

Included in this quotation

Public site

Landing, About & Terms

  • Msheireb Properties branding, logo, and colour system
  • Hero, how it works, featured projects, FAQ, footer
  • Welcome bonus banner
  • About and Terms pages, editable from admin
  • Telegram / WhatsApp support and “List your property” links
Accounts

Registration & login

  • Signup with name, mobile, and password
  • Login, session handling, forgot password
  • Short 5–6 digit member IDs
  • Welcome bonus on approved accounts
  • Account statuses: active, pending, blocked, suspended
Rewards

Projects, sets & orders

  • Project groups with Set 1 / 2 / 3
  • Admin lock/unlock of groups and sets per user
  • Order flow with commission credited to wallet
  • Trial wallet, hold balance, daily reset logic
  • Premium projects and fortune-box items per member
Money

Wallet & cash-out

  • Main wallet ledger and transaction history
  • Cash-in via Telegram
  • Cash-out requests with withdrawal password
  • Bank and/or crypto payout accounts
  • Admin approve / reject with refund on rejection
Admin

Operations panel

  • User directory, search, status, wallet adjustment
  • Change login and withdrawal passwords
  • Delete a member and all related records
  • Cash-out queue and full transaction log with member ID
  • Catalog, settings, min cash-out, bonus, support links
Delivery

Setup & handover

  • Separate database and admin login for Msheireb
  • Source code of client, admin, and API
  • Environment setup notes and first-run seed
  • One round of branding revisions (logo, colours, copy)
  • Walkthrough of admin after delivery
